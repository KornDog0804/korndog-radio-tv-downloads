# KornDog Radio TV - staging downloads

Test builds of the KornDog Radio TV Android TV app. **Staging only, not a release.**

- `KornDogRadioTV-staging.apk`: the current staging build (always the same file name)
- `SHA256SUMS.txt`: checksum to verify the download

The APK contains no passwords, server keys or tokens. Source code lives in a private repository.
